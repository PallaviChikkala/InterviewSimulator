# Interview Simulator

A backend REST API for an Interview Simulator application built using Spring Boot and MySQL.

The project provides APIs to manage interview questions and supports CRUD operations, category-based filtering, DTOs, and exception handling.

## Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- REST API
